## ⚡ About

**Desktop OS portfolio** — *macOS-inspired, fully vanilla `HTML/CSS/JS` — no frameworks, no build — transforms a static portfolio into an interactive operating system.*

<img src="https://readme-typing-svg.demolab.com/?font=JetBrains%20Mono&size=13&duration=1800&pause=600&color=8b5cf6&center=false&vCenter=true&width=800&height=22&lines=%3E+booting+Abhishek-Portfolio...; %3E+wallpaper+Unsplash+%2B+Lottie+%2B+particles+%E2%9C%93; %3E+windowIn+0.38s+%E2%80%A2+iconPulseGlow+2.8s+%E2%9C%93; %3E+Wavecont+2%3A24+%E2%80%A2+single-window+%E2%80%A2+View%E2%86%92GitHub+%E2%9C%93; %3E+Ask+Abhi+local+AI+%E2%80%A2+offline+%E2%9C%93; %3E+Portfolio+ready+%E2%80%94+desktop+OS+%E2%9C%A8" alt="boot"/>

- **Desktop:** `ABHISHEK` centered (static) + `0xAbhi13` menu + `wallpaper` `Unsplash` `photo-1531297484001` + `particleCanvas` `56 dots` + `GSAP parallax` on wallpaper only
- **Windows (single):** `Finder` `About` `Projects` `Skills` `Certifications` `Photos` `Resume (Coming Soon)` `Contact` `Terminal` `Ask Abhi` — **1 at a time** `8px` clamp, draggable, resizable, `windowIn 0.38s` `scale 0.88→1` `blur 6px`
- **Projects (7):** `Developer Portfolio` (`MyPortfolio`) • `0xBeatForge` (Web Audio) • `0xPDFForge` (PDF) • `0xEmotion` • `0xMagicSearch` • `0xAirCanvas` • `0xVoiceVision` — **View →** directly opens GitHub
- **Music:** `Wavecont - Uplifting Acoustic` `2:24` `assets/audio/wavecont.mp3` (`5799547` bytes) — `file://` + `http://` both work, `preload metadata`, `2:24` placeholder (no `0:00`)
- **Icons:** `assets/icons/*.svg` `14` professional `96×96` `linearGradient #8b5cf6→#4f46e5` — `iconPulseGlow 2.8s` `iconGradientShift 8s` `bounce 0.45s` on hover
- **Favicon:** premium `favicon.svg` `64×64` `rx18` `0x ABHI 13`

**1. Clone**
```bash
git clone https://github.com/0xAbhi13/Abhishek-Portfolio.git
cd Abhishek-Portfolio
```

<img src="https://readme-typing-svg.demolab.com/?font=JetBrains%20Mono&size=13&duration=1600&pause=500&color=06b6d4&width=700&height=20&lines=%24+python+-m+http.server+8000+%23+or+double-click+index.html" alt="run"/>

```bash

python -m http.server 8000
# open http://localhost:8000/  →  ▶ Wavecont 2:24 → View→GitHub
```

**3. Deploy — GitHub Pages (no build)**
```bash
git init; git add .; git commit -m "feat: Abhishek desktop OS — 7 projects, Wavecont, single-window"
gh repo create Abhishek-Portfolio --public --source=. --push
# Settings → Pages → Deploy from branch → main / (root) → Save
# Live: https://0xabhi13.github.io/MyPortfolio/  (primary)
```

## 🎬 Motion — Animation Architecture

<div align="center">
<img src="https://img.shields.io/badge/Boot-3s_•_shimmer-8b5cf6?style=flat-square"/> <img src="https://img.shields.io/badge/Wallpaper-GSAP_parallax-06B6D4?style=flat-square"/> <img src="https://img.shields.io/badge/Icons-pulseGlow_2.8s-f472b6?style=flat-square"/> <img src="https://img.shields.io/badge/Window-windowIn_0.38s-a78bfa?style=flat-square"/> <img src="https://img.shields.io/badge/Music-Wavecont_2:24-f59e0b?style=flat-square"/>
</div>

- **Boot** `js/app.js:4` — `steps 5` `420ms` → `bar 0→100%` `shimmer 1.2s` → `hide 3s` `opacity 0.6s` `sessionStorage booted` — `capsule-render twinkling` + `typing SVG 2000ms`
- **Wallpaper** `js/app.js:25` `initOnlineGraphics` — `particleCanvas 56` `r 1.1` `line 120px` `rgba(139,92,246,0.08)` + `GSAP wallpaper parallax x-6 y-4` `1.2s` — **ABHISHEK static**
- **Icons** `css/style.css:22` — `iconPulseGlow 2.8s` `iconGradientShift 8s` `iconBounce 0.45s` on hover — **no float**
- **Windows** `css/style.css:31` — `windowIn 0.38s` `scale 0.88→1.02→1` `blur 6px` `cubic-bezier(0.16,1,0.3,1)` — **single-window** `js/app.js:155` closes others
- **MusicBar** `js/music-player.js:119` — `preload metadata` `crossOrigin=''` `wavecont.mp3 2:24` — `file://` + `http://` both
- **Every app** — `lucide.createIcons()` after `renderWindows`, `spotlight Ctrl+K`, `phoneTime` `tickTime`
