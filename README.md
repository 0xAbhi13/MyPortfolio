## 📦 Getting Started

<details open>
<summary><b>🖱️ Click to expand setup steps</b></summary>

<br/>

**1. Clone the repo**

```bash
git clone https://github.com/0xAbhi13/MyPortfolio.git
cd MyPortfolio
```

**2. Open it locally**

```bash
open index.html
```

> No build step, no dependencies — just plain HTML, CSS, and JS.
